Über diesen Monitor

GitHub Actions lädt täglich die öffentlichen opendata.swiss-Metadaten. Für den Zeitraumvergleich werden zwei vollständig gespeicherte Tagesstände gegenübergestellt, unabhängig davon, ob sie direkt aufeinanderfolgen.

„Neu“ bedeutet neu in der Abfrage; „Entfernt“ bedeutet, dass ein Datensatz in der neueren Abfrage nicht mehr enthalten ist, nicht zwingend, dass er gelöscht wurde. Änderungen betreffen Metadaten, nicht die Inhalte extern verlinkter Dateien.

Ein fehlender Prüftag ist kein Nachweis, dass sich an diesem Tag nichts geändert hat. Für bereits vorhandene ältere Tagesstände müssen diese nach dem Aktualisieren von opendata_monitor.py durch einen neuen Workflow-Lauf in das Webarchiv kopiert werden.
